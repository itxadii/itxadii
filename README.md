## 👨‍💻 About Me

I’m **Aditya Waghmare**, a Cloud/DevOps Engineer focused on building scalable and automated infrastructure on AWS.

I specialize in:
- Deploying **serverless and containerized** workloads on AWS (ECS Fargate, Lambda, EventBridge, S3, IAM)
- Automating infrastructure using **Terraform & GitHub Actions**
- Containerizing applications using **Docker** and deploying them with proper networking and security
- Writing automation scripts using **Python (Boto3)** and **Bash**

My approach is straightforward:  
**Infrastructure should be reliable, repeatable, and automated.**
